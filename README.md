Для PySide: Язык - python, GUI-фреймворк: PySide6 API и подход полностью совпадают с PyQt6, для графики, виджетов и логики используются те же компоненты Qt, установка через pip: pip install pyside6.

Для Tkinter: Язык - python, GUI-фреймворк: Tkinter — стандартная библиотека Python для построения графических интерфейсов, работает с интерфейсами на основе Tcl/Tk, простая и кроссплатформенная, но менее функциональная по сравнению с Qt, поддерживает базовые виджеты, позиционирование через geometry менеджеры (place, pack, grid), pip install pillow для работы с изображениями.
